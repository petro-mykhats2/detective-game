# Оновлення проєкту «Детектив» — виправлення стартового екрана та сцена 1

Це патч для наявного проєкту React + TypeScript + Vite. Архів містить файли `src/` для копіювання до проєкту, а не повний застосунок із `package.json`.

## Що містить патч

- `src/App.tsx` — наявний екранний цикл із класом `is-ready` на кореневому елементі та підключенням сцени `ChiefOffice`.
- `src/scenes/ChiefOffice/ChiefOffice.tsx` — компонент першої сцени з текстом, індикатором прогресу та кнопкою переходу.
- `src/scenes/ChiefOffice/sceneData.ts` — вісім текстових реплік і шляхи до аудіофайлів.
- `src/game/` та `src/storage/` — базові типи стану гри, дії, умови та збереження.
- `src/App.css`, `src/index.css` — стилі екранів.

## Застосування

1. Зробіть резервну копію `src/` у своєму проєкті.
2. Розпакуйте архів і скопіюйте вміст папки `detective-intro-update/src/` у папку `src/` вашого проєкту, дозволивши об'єднання каталогів і заміну файлів.
3. Не замінюйте `package.json`, `package-lock.json`, `index.html` або `src/main.tsx`.
4. Перевірте, що в `public/` вашого проєкту на місці `background.jpeg` і `investigation-theme.mp3`.
5. Для озвучення реплік покладіть файли `intro-01.mp3` … `intro-08.mp3` у `public/audio/`. Якщо їх немає, текст можна гортати вручну.
6. Із кореня проєкту виконайте `npm run dev`.

## Важливо

Причина чорного стартового екрана, яку видно в коді цього пакета: стилі показують фон і вступний екран лише за наявності класу `is-ready`; кореневий елемент `App` має цей клас. Це виправлення ще потрібно перевірити запуском саме у вашому локальному проєкті. Цей архів не містить ваших медіафайлів або `package.json`.
