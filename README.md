# Детективна платформа — перший екран, прототип 0.1

## Застосування
1. Зупини Vite у терміналі: `Control+C`.
2. За бажанням зроби копії поточних `src/App.tsx`, `src/App.css`, `src/index.css`.
3. Скопіюй однойменні файли з папки `src` цього архіву до `src` твого проєкту `detective-game`, замінивши старі.
4. Перевір, що `src/main.tsx` імпортує `./index.css` та рендерить `<App />` (у шаблоні Vite це вже є).
5. Запусти `npm run dev` і відкрий адресу з термінала.

Це лише інтерфейсний прототип. Тексти документів, механіки доказів і збереження прогресу ще не реалізовані. Вікно документа чесно повідомляє, що потрібен точний оригінальний текст; факти справи не вигадуються.
